# AI Documentation Bank

This directory is a compact working knowledge base for contributors and coding assistants. Keep entries factual, short, and close to the code they describe.

## Documents

- [Project context](project-context.md): architecture, important paths, and validation commands.
- [Pi operations](pi-operations.md): how to connect to the device and run repository scripts there.

## Documentation rules

- Record stable repository facts, decisions, and operational procedures.
- Link to the source file or command when a detail may change.
- Update the relevant entry when behavior changes; do not keep speculative notes as facts.
- Never commit credentials, private hostnames, personal usernames, API keys, or other machine-specific secrets.
- Store private machine values in local shell configuration such as `~/.bashrc`.
